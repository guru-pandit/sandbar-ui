# Changesets

This directory contains changeset entries for the `@panux-ui/*` packages, managed by [Changesets](https://github.com/changesets/changesets).

Run `pnpm changeset` after any change to a publishable package (`packages/*`, excluding the apps) to record what changed and at what semver bump. See `.claude/agents/documenter.md` and the `/ship` command for how this fits into the project's review workflow.
