Add the first fully-realized styled components with real vanilla-extract recipes and variant props: `Stack`/`Container`/`Center` (Layout) and `Text`/`Heading` (Typography — `size`/`weight`/`color`, with `Heading`'s semantic `level` decoupled from visual `size`). Each ships with unit tests, an axe a11y test, a Storybook story, and an MDX docs page with an auto-generated props table. Fixed the recipe file naming convention project-wide: vanilla-extract only processes files ending in `.css.ts`, not `.recipe.ts` as originally documented.
