## Customization

- **Adding a new `gap`/`align` step**: add a step to the relevant `variants` block in `Wrap.css.ts`'s `wrapRecipe`.
- **Changing the default**: set `defaultVariants` in the recipe (currently `gap: 'sm'`, `align: 'start'`).

## Accessibility

`Wrap` has no semantics of its own — it's a visual flex wrapper. If its children form a list of equivalent items (e.g. a tag list), consider whether a native `<ul>`/`<li>` structure (via `as="ul"` and rendering `as="li"` children) better conveys that to assistive technology than a generic `<div>`.

## Composition

A filter chip list that grows with an unknown number of active filters:

```tsx
<Wrap gap="sm">
  {activeFilters.map((filter) => (
    <Tag key={filter.id} onRemove={() => removeFilter(filter.id)}>
      {filter.label}
    </Tag>
  ))}
</Wrap>
```

## Styling

`gap` and `align` are vanilla-extract recipe variants reading from the static token contract — see `Wrap.css.ts`. Override with `className`/`style` for anything the variants don't cover.
