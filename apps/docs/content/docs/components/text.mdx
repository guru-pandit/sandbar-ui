## Styling

`size`/`weight`/`color` are vanilla-extract recipe variants — see `Text.css.ts`. `color` reads semantic tokens (`fg.default`, `fg.muted`, `accent.text`, `danger.text`), so it automatically follows the active theme (`light`/`dark`/`contrast`).
