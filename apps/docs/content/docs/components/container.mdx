## Styling

`size` maps to a `max-width` breakpoint. These are currently literal pixel values, not tokens — `packages/tokens` doesn't have a breakpoint scale yet (see `Container.css.ts`); promoting them to real tokens is tracked for whenever a second component needs the same values.
